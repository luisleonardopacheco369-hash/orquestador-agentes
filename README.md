# orquestador-agentes

Nara es un agente visible dentro de un mundo que puedes moldear.

Esculpe el terreno con el pincel, pide cambios en español («un lago en el centro», «un bosque al norte», «abre un río») y cambia también la forma y el color de Nara.

## Desarrollo

```bash
npm ci
npm run dev
```

Abre `http://localhost:5173`.

## Pruebas

```bash
npm test
npm run build
```
